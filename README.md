## Gesture-Controlled Rover
**ESP32 · Computer vision · L298 motor driver**

A four-wheeled rover driven by hand gestures. A webcam on a PC runs a hand-detection model, turns recognised gestures into motion commands, and sends them to an ESP32 that drives the motors in real time. Perception and embedded control are kept as separate modules.

## Shape-Changing X-Link Rover
**ESP32 · Ultrasonic sensors · Servo · Embedded C++**

A rover that changes its own chassis width to fit through tight spaces. Ultrasonic sensors measure the distance on each side, and the ESP32 drives a servo to expand or contract the chassis based on those readings. Movement is controlled separately through an ESP32-hosted web interface.

## Robotic Arm
**ESP32 · Servo motors · Blynk IoT**

A robotic arm controlled from a phone. Joystick and slider widgets in a Blynk mobile app send commands to an ESP32, which drives servo motors for the arm joints and gripper and an L298 motor driver for base movement.

## Automatic Irrigation System
**ESP8266 · Soil moisture & DHT11 sensors · Blynk IoT**

Waters plants automatically based on soil moisture, temperature and humidity. The ESP8266 reads the sensors, switches a water pump through a relay when readings cross set thresholds, and shows live data on a mobile app.
